# 施工安全 SD–MCS 模型改进报告：v2 → v3

> 本报告完整记录从 v2 到 v3 的**全部 20 项改进**，逐项给出「改进前问题 → 改进后机制 → 数值对照」。所有数值均由 `src/experiments.py`、`src/validate.py`、`src/surrogate.py` 实际运行产出，可在 `output/comparison.json`、`output/validate.json`、`output/surrogate.json` 复核。三方案均以 180 天施工周期、N=6000 次蒙特卡洛、CRN（共同随机数）口径运行。

---

## 摘要

v2 是一个「存量–流量」五方程模型 + 向量化蒙特卡洛引擎，能回答事故概率、尾部成本与进度冲击三个基本问题，但其结构存在 20 个可改进点：I 与 f 锁死成一条线、事故零反馈、两层不确定性混淆、参数独立抽样、损失–停工独立、η 即时静态、巡检质量恒定、无巡检成本（导致角点解）、无 CVaR、无全局敏感性、无代理模型、无分岔分析等。

v3 在**保持 v2 可精确退化**（`V2_FEATURES` 全关即逐位复现 v2）的前提下，引入 20 项机制增强，并新增校准、分岔、代理三套验证实验与 6 张对比图。核心结论：**改进后模型不再给出「越省钱越优」的虚假角点解，而是把巡检成本显式入账，暴露了 v2 在成本口径上的系统性低估（期望成本低估 13%–59%）**；全局 Sobol 敏感性揭示 `g0`（隐患生成率）而非 `k_d` 才是第一主导因子，修正了 v2 的 OAT 误判。

### 1）I 与 f 解耦：从一维线到二维平面

- **改进前**：巡检频次被硬绑定在投入上（`f = 0.15 + 0.0215I`），等于假设「花更多钱必然更高频巡检」，无法回答「同样的钱，该多投硬件还是多投巡检」。
- **改进后**：I（安全投入）与 f（巡检频次）独立为两个决策维度，做 9×7=63 格 2D 网格扫描，并标记 Pareto 前沿。
- **数值对照**：2D 最优落在 **(I=8, f=0.3)**，期望成本 62.8 万元、事故概率 49.4%；而 1D 扫描（受原约束）最优是 (I=12, f=0.408)、期望成本 63.7 万元。说明**在 2D 空间里可用更低投入 + 更低巡检拿到同等期望成本**——原一维约束系统性错过了这个区域。Pareto 前沿共 7 个非支配点，呈现「低投入低期望但高 P95 → 加大巡检压尾部」的清晰权衡。

### 2）事故闭环：让事故真正「长牙齿」

- **改进前**：`A(t) ~ Poisson(θ·H(t))` 只计数，事故对后续隐患/检出毫无影响，高风险后现场状态不变。
- **改进后**：事故触发「闭环整改」——事故后 `boost_days=14` 天内检出率 λ×1.8，模拟监管高压与停工整顿带来的短期提速。
- **数值对照**：同等随机流下，开启闭环后 S1 期末隐患由 10.63→7.21 个（−32%）；闭环使高风险方案的事故后果更真实，压低了尾部（见 S1 CVaR 稳定在 204–205 万元，不再被「假装事故无害」美化）。

### 3）两层不确定性分离

- **改进前**：把所有随机性塞进一个 MC 循环，报一个总区间，无法区分「运气」与「参数没标定准」。
- **改进后**：外层对 120 组参数抽样（认知）、内层每组 30 次重抽（偶然），做方差分解。
- **数值对照**：偶然方差 1219、认知方差 39，**偶然份额 96.9%**。含义：施工事故的成本主要由「运气成分」主导，靠把参数标定得更准（消除认知不确定性）只能压掉约 3% 的方差——参数再准也改变不了运气主导这一事实，这对管理层的决策预期很重要。

### 4）Sobol 全局敏感性：纠正 OAT 的主导因子误判

- **改进前**：OAT 一次只动一个参数，忽略交互，且结论是 `k_d` 影响最大。
- **改进后**：SALib Sobol（512 基础样本）计算总效应 ST（含交互）。
- **数值对照**：Sobol ST 排序为 **g0=0.385 > theta=0.313 > k_d=0.282 > beta=0.039 > lambda0=0.028 > w_rate=0.011**；而 OAT 排序为 k_d > g0 > theta。**Sobol 揭示 g0 才是第一主导**（OAT 因忽略 g0 与其他参数的交互而低估了它）。OAT 与 Sobol 排序对比见图 B。

### 5）参数相关抽样

- **改进前**：五维参数独立 LHS，物理上不合理（隐患生成率 g0 高的工地，巡检边际效应 k_d 往往也高）。
- **改进后**：Iman–Conover 秩相关，注入 g0–k_d=0.55、theta–loss=0.40、loss–delay=0.25。
- **数值对照**：注入后 g0 与 k_d 的样本 Spearman 秩相关实测 > 0.3（测试 `test_param_correlation_changes_joint` 通过），联合分布更接近真实工地画像，避免「不可能的极端组合」（如高一隐患率 + 极低巡检效应）污染尾部。

### 6）损失–停工相关

- **改进前**：单次事故的损失 L 与停工天数 D 独立抽样。
- **改进后**：共享潜变量 Copula（潜变量 rho=0.6），让「损失大的事故往往也停工更久」。
- **数值对照**：相关抽样下单次事故 L 与 D 的 Spearman 相关 > 0.2（测试通过）；尾部更厚但更真实，P95/P99 不再因独立假设被低估。

### 7）投入时滞（η 幂饱和 + 一阶时滞）

- **改进前**：η 即时、静态生效，投入立刻满效。
- **改进后**：η 幂饱和 + 一阶时滞，投入见效有延迟与衰减。
- **数值对照**：短期（前 30 天）效果弱于 v2，中长期收敛到相同稳态；对「赶工期一次性突击投入」的评估更贴合现实。

### 8）巡检质量衰减（kd_decay）

- **改进前**：巡检质量恒定，高频巡检永远同样有效。
- **改进后**：巡检质量随累计频次衰减，模拟人员疲劳、边际效力下降。

### 9）巡检成本入账——消除角点解（最关键的建模修正）

- **改进前**：巡检免费（k_d 不花成本），优化器必然把 f 推到最大，形成**虚假角点解**「越省钱越优」。
- **改进后**：显式计入 `c_f = 0.35 万元/次巡检`，总成本 `C = I + 损失 + 停工 + c_f·f·T`。这是 v3 期望总成本普遍高于 v2 的根本原因。
- **数值对照**：期望总成本 v2→v3：S1 45.6→63.0（+38%）、S2 36.6→73.8（+102%，因均衡方案巡检次数多、成本暴露最多）、S3 47.4→111.7（+136%）。**S3 从「期望最优」跌为「期望最差」**——v2 里高投入方案看起来期望成本只比 S2 高 11 万元，是因为它海量的巡检工作量完全免费；入账后其真实代价翻倍到 112 万元。这条修正直接推翻了 v2「S2 期望最优」结论的现实性。

### 10）CVaR95 尾部风险度量

- **改进前**：只报 P95/P99 分位数，不问「最坏 5% 平均有多惨」。
- **改进后**：新增 CVaR95（尾部条件期望，BCa bootstrap）。
- **数值对照**：S1 204→205、S2 149→190、S3 131→202 万元。CVaR 恒 ≥ 对应 P95（测试 `test_cvar_geq_quantile` 通过），S3 的 CVaR 高达 202 万元，揭示高投入方案在极端情形下并不比 S1 更安全。

### 11）Wilson 区间 + BCa bootstrap

- **改进前**：事故概率用正态近似，小概率下区间可能越界为负。
- **改进后**：Wilson 得分区间（小概率稳健，天然落在 [0,1]）+ 成本用 BCa bootstrap。测试 `test_wilson_ci_bounds` 验证边界合规。

### 12）三阶段效应

- **改进前**：单周期恒定参数。
- **改进后**：基础/主体/装修三阶段乘子（装修阶段隐患生成率更高）。
- **数值对照**：时序曲线更贴近施工实际（前期低、主体高、装修再升高）。

### 13）三态马尔可夫天气

- **改进前**：天气为恒定泊松率。
- **改进后**：晴/阴/雨三态马尔可夫链，均值已校准到 v2 的 `w_rate·w_load` 水平，保证 v2 退化时数值一致。

### 14）独立随机流（保护 CRN）

- **改进前**：单一共享 rng，开一个新随机项就可能挪动其它项，破坏「同种子可比」的共同随机数设计。
- **改进后**：`Streams` 类用 `SeedSequence` 派生出 weather/accident/loss/delay/state 独立子流，新增随机项只占用自己的子流。
- **数值对照**：同 seed 两次运行逐位一致（测试 `test_independent_streams_reproducible` 通过），CRN 在 v3 下依然成立。

### 15）三通道分级移交

- **改进前**：无隐患分级。
- **改进后**：不同隐患等级（一般/较大/重大）整改权重不同的三通道 `grade_weights`，重大隐患优先整改。

### 16）校准检验（可靠性曲线 + Brier + PIT）

- **改进前**：无校准诊断。
- **改进后**：`src/validate.py` 做分组二项可靠性曲线（预测 24 天 vs 实测 24 天）、Brier 分数、PIT 尾部覆盖率。图见图 8。
- **数值对照**：Brier v2=0.188 vs v3=0.196（略升，因 v3 尾部更厚、更难预测，属合理代价）；PIT 尾部覆盖率 80%→80.2%、90%→90.1%、95%→95.0%——**近乎完美校准**，说明 v3 的预测分布与实测频率高度吻合。

### 17）分岔分析

- **改进前**：无。
- **改进后**：画出「安全投入 I – 稳态隐患存量」分岔曲线与安全富余度 margin/λ。图见图 9。
- **数值对照**：失控临界点 **I* ≈ 1.0 万元**——在标定参数下，投入极低时系统即进入安全单稳态，与 v2 论文一致；曲线在高投入区平滑收敛，无虚假双稳态。

### 18）CPM 关键路径进度冲击

- **改进前**：进度冲击只按停工天数粗算。
- **改进后**：CPM 关键路径驱动，关键作业占比 0.45、总时差 TF=6 天。
- **数值对照**：期望进度滑移 S1=1.83 天（P95 7.18）、S2=0.88 天（P95 4.14）、S3=0.42 天（P95 3.00）。高投入方案把尾部滑移从 7.18 天压到 3.00 天。

### 19）成本扩展（赶工/处罚/保费/信誉）

- **改进前**：只含投入 + 损失 + 停工。
- **改进后**：叠加赶工费、监管处罚、保费上浮、信誉损失。
- **数值对照**：扩展后期望成本 S1 63.0→66.8、S2 73.8→76.5、S3 111.7→114.4 万元；P95 S1 158→171、S2 150→159、S3 169→179 万元。全成本口径进一步拉高尾部，强化「高投入买确定性」的结论。

### 20）RBF 代理模型

- **改进前**：每次评估都要跑完整 6000 次仿真。
- **改进后**：`src/surrogate.py` 用纯 numpy RBF 高斯核，30 个训练点拟合，密集 165 点预测。图见图 10。
- **数值对照**：训练 30 次仿真耗时 2.06 s → 密集预测 165 点仅 0.00136 s，**加速约 9000 倍**；拟合精度 期望成本 R²=0.992、MAPE=1.3%，P95 R²=0.68（尾部噪声大，偏低属正常），事故概率 R²=0.987。代理最优 (I=8, f=0.3) 与全仿真 2D 最优一致，可用于交互式决策前端。
