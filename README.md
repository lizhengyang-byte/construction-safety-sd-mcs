# construction-safety-sd-mcs

**系统动力学（SD）+ 蒙特卡洛模拟（MCS）耦合的土木工程施工安全风险量化框架**

给定一笔安全投入和一套巡检安排，回答项目管理真正需要的三个问题：一个施工周期内至少发生一次事故的概率是多少？总成本的最坏情况（P95/P99）有多差？事故停工对进度基线的期望冲击有多大？

配套论文：飞书文档《基于系统动力学与蒙特卡洛耦合的土木工程施工安全风险量化研究》，位于云盘 `土木工程 / 07_施工安全SD-MCS仿真`。

## 模型概要

以「未整改隐患存量」为核心存量的存量—流量模型，日步长推演：

```
H(t+1) = H(t) + G(t) + W(t) - R(t) - A(t)
G(t)   = g0 * (1 + beta*H(t)) * (1 - eta)      # 隐患生成（正反馈放大）
eta    = 1 - exp(-k_t * I)                     # 安全投入的培训抑制率
R(t)   = (lambda0 + k_d * f) * H(t)            # 巡检整改（负反馈调节）
A(t)   ~ Poisson(theta * H(t))                 # 隐患→事故的泊松转化
C      = I + sum(L_i) + c_d * sum(D_i)         # 投入 + 损失 + 停工损失
```

- **决策变量**：安全投入 I（万元/周期）、巡检频次 f（次/天）
- **随机参数（四维拉丁超立方抽样）**：g0、theta、损失中位数 m_L、停工中位数 m_D
- **输出**：事故概率、期望事故次数、期望/分位数成本、期望停工、期末隐患存量

## 主要结果（180 天周期，N = 6000）

| 方案 | 投入 | 巡检 | 事故概率 | 期望事故次数 | 期望总成本 | P95 成本 | 期末隐患 |
|---|---|---|---|---|---|---|---|
| S1 低投入 | 8 万元 | 0.32 次/天 | 47.9% | 0.64 | 44.0 万元 | 146.4 万元 | 10.0 个 |
| S2 均衡 | 20 万元 | 0.58 次/天 | 24.1% | 0.27 | 36.2 万元 | 109.9 万元 | 4.1 个 |
| S3 高投入 | 40 万元 | 1.00 次/天 | 10.5% | 0.11 | 46.6 万元 | 94.3 万元 | 1.6 个 |

三条结论：

1. **期望最优 ≠ 尾部最优**：期望成本最低的是 20 万元方案（36.2 万元），P95 成本最低的是 40 万元方案（94.3 万元）。
2. **边际效益拐点在 15—20 万元**：8→20 万元每万元投入削减事故概率 1.98 个百分点；20→40 万元区间降为 0.68 个百分点。
3. **敏感性集中于三处**：巡检边际效应 k_d（±30% → 期望成本 +6.3 / −3.1 万元）、事故触发系数 theta（+5.9 / −4.6）、隐患生成率 g0（+5.3 / −4.5）；天气扰动影响不足 1.5 万元。

## 边界与免责

- 参数为**示例标定值**（台账反演 + 文献区间），未经现场实测校准，用于方法演示与方案比选，不可直接作为具体工程决策依据。
- 模型为聚合型：无空间分辨率、无个体行为异质性，投入—检出关系采用线性近似，未刻画饱和与时滞。
- 改进方向：贝叶斯更新参数、幂函数饱和效应、分段标定、Sobol 全局敏感性、与 BIM 分区清单耦合。
