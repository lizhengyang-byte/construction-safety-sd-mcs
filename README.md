# construction-safety-sd-mcs

**系统动力学（SD）+ 蒙特卡洛模拟（MCS）耦合的土木工程施工安全风险量化框架**

给定一笔安全投入和一套巡检安排，回答项目管理真正需要的三个问题：一个施工周期内至少发生一次事故的概率是多少？总成本的最坏情况（P95/P99）有多差？事故停工对进度基线的期望冲击有多大？

本项目是完整可复现的模型代码与实验脚本，配有论文（飞书文档与 [`docs/paper.md`](docs/paper.md) 两个同源版本）、十张 SVG 矢量图、单元测试与 CI。

> **v3 已发布**：在 v2 基础上完成 20 项机制增强（I/f 解耦、事故闭环、两层不确定性、Sobol 全局敏感性、参数相关抽样、巡检成本入账、CVaR、独立随机流、校准/分岔/代理模型等），并产出完整的改进前后对照。详见 **[`docs/improvement_report.md`](docs/improvement_report.md)**。v3 通过 `FEATURES` 开关字典可**逐位退化为 v2**，保证改进可加、可回退、可逐项归因。
>
> **v3.1 博弈论 / 运筹学扩展**：在 v3 之上新增四个模块——运筹决策层（期望/CVaR/鲁棒随机规划求最优 (I,f)）、监管–承包商 Stackelberg 博弈与威慑门槛、多承包商公地悲剧、蒙特卡洛方差缩减与主动学习。详见 **[`docs/game_or_report.md`](docs/game_or_report.md)**。

## 一、模型概要

```
H(t+1) = H(t) + G(t) + W(t) - R(t)
G(t)   = g0 * (1 + β*H(t)) * (1 - η)           # 隐患生成（含正反馈放大）
η      = 1 - exp(-k_t * I)                     # 安全投入的培训抑制率
R(t)   = λ * H(t),  λ = 1 - exp(-(λ0 + k_d*f)) # 巡检整改，检出率封顶为 1
A(t)   ~ Poisson(θ * H(t))                     # 隐患→事故；只计数，不扣减存量
C      = I + Σ L_i + c_d * Σ D_i               # 总成本 = 投入 + 损失 + 停工损失
```

两处建模约定：

- **事故不消除隐患。** 事故发生后现场隐患通常仍然存在；若把每次事故从存量里扣除，会系统性低估存量、美化高风险方案，因此 `A(t)` 只作计数。
- **检出率封顶。** 线性式 `λ0 + k_d·f` 在频次很高时会给出大于 1 的检出率，故改用指数封顶式，保证物理意义成立。

**随机参数（五维拉丁超立方抽样）**：`g0`、`θ`、`m_L`、`m_D` 与巡检边际效应 `k_d`。`k_d` 在敏感性分析中影响最大，若固定处理等于默认"最敏感的参数恰好标定准确"，故纳入抽样。

**输出**：事故概率、期望事故次数、期望成本与 P95/P99、期望停工、期末隐患量，均附 95% 置信区间（800 次 bootstrap；事故概率按二项标准误）。

## 二、共同随机数：让比较只反映参数差异

三套方案、九个投入档位、十二组敏感性扰动**共用同一组拉丁超立方样本（seed 2026）与同一随机数流（seed 7）**：

- 方案 S2（I=20）与扫描档位 I=20 结果完全相等（36.28 万元）；
- 敏感性基准就是均衡方案本身（36.28 万元），不会出现基准与主实验对不上；
- 方案与档位之间的差异不含抽样噪声，小幅差异可解读为结构性差异。

代价是不再能靠"多抽几个种子互证"掩盖误差，因此所有报告值都附置信区间。

## 四、运行与验证

```bash
pip install -r requirements.txt
python src/experiments.py   # 三方案 + 两层不确定性 + Sobol + 2D 网格 + 进度 + 成本扩展
python src/validate.py      # 校准 + 分岔
python src/surrogate.py     # RBF 代理模型
python src/compare_figs.py  # v2-vs-v3 对比图
python src/or_opt.py        # 运筹决策层：期望/CVaR/鲁棒最优 (I,f)
python src/game.py          # 监管–承包商 Stackelberg 博弈 + 威慑门槛
python src/game_multi.py    # 多承包商公地悲剧
python src/mc_advanced.py   # MC 方差缩减 + 主动学习
python src/render_svg.py    # 生成 docs/figures/*.svg

```

CI 在每次推送时跑单元测试与完整实验，并校验关键指标是否落在预期区间（含共同随机数一致性、置信区间包住点估计）；`figures.yml` 会在代码变更后重建 SVG 并自动提交。

## 五、主要结果

### 5.1 v2 基线（180 天周期，N = 6000，`V2_FEATURES` 精确退化）

| 方案 | 投入 | 巡检 | 事故概率 [95% CI] | 期望事故次数 | 期望总成本 [95% CI] | P95 成本 | 期末隐患 |
|---|---|---|---|---|---|---|---|
| S1 低投入 | 8 万元 | 0.32 次/天 | 48.1% [46.9, 49.4] | 0.66 | 46.3 [44.9, 47.6] | 155.4 | 10.6 |
| S2 均衡 | 20 万元 | 0.58 次/天 | 25.2% [24.1, 26.3] | 0.29 | 36.3 [35.4, 37.1] | 108.0 | 4.2 |
| S3 高投入 | 40 万元 | 1.00 次/天 | 11.9% [11.1, 12.8] | 0.13 | 47.4 [46.9, 48.1] | 98.9 | 1.7 |

### 5.2 v3 改进后（全特性，巡检成本入账）

| 方案 | 事故概率 | 期望总成本(万元) | P95 成本 | P99 成本 | CVaR95 | 期望进度滑移(天) | 期末隐患(个) |
|---|---|---|---|---|---|---|---|
| S1 低投入 | 48.6% | 63.0 | 157.9 | 230.9 | 204.6 | 1.83 (P95 7.18) | 7.21 |
| S2 均衡 | 26.4% | 73.8 | 150.5 | 214.2 | 190.0 | 0.88 (P95 4.14) | 3.12 |
| S3 高投入 | 14.0% | 111.7 | 169.4 | 218.1 | 202.4 | 0.42 (P95 3.00) | 1.46 |

### 5.3 主要结论

1. **期望最优 ≠ 尾部最优（v3 更尖锐）。** v2 中期望成本最低的是 S2（36.3 万元），因为巡检全部免费；v3 把巡检成本入账后，S2 期望成本升至 73.8 万元，**S3 由「期望仅贵 11 万」变为「贵 38 万」——高投入的真实代价被揭示**。P95 上 S2（150.5）仍低于 S3（169.4），买确定性而非期望收益的结论不变，但量级更真实。
2. **全局敏感性主导因子修正。** OAT 曾显示 `k_d` 最敏感；Sobol 总效应揭示 **`g0`（隐患生成率，ST=0.385）才是第一主导**，`theta`(0.313)、`k_d`(0.282) 次之。管理启示应从「多巡检」转向「源头降低隐患生成」。
3. **运气主导成本方差。** 两层不确定性分解显示偶然不确定性占 **96.9%**，参数标定再准也只能压掉约 3% 方差——事故成本本质由运气主导。
4. **模型自洽且校准良好。** 解析稳态 vs 仿真相对误差 <1%；PIT 尾部覆盖率 80/90/95% 档分别为 80.2/90.1/95.0%，近乎完美校准。

### 5.4 博弈论 / 运筹学扩展（v3.1）

| 模块 | 关键结论 |
|---|---|
| 运筹决策层 | 期望最优 I=6,f=0.40（E[C]=61.1 万元，压到最低投入）；CVaR 最优 I=6,f=0.80（E[C]=72.8，CVaR 183.2）。多花 11.7 万期望可把 CVaR 压 19.0 万、超预算概率 3.2%→2.0%——风险厌恶靠提高巡检频次压尾部。 |
| 监管–承包商博弈 | 事故处罚/赔付基数 **L_acc\*≈200 万元**是威慑门槛：低于此承包商维持偷工+低投入；Stackelberg 均衡 e\*=0（重罚到位后额外监查多余、效率损失归零）。先立重罚、再谈检查。 |
| 多承包商公地悲剧 | 5 家 Nash 单家 I=6（总 30 万）vs 社会最优 I=12（总 60 万），**缺口 50%**；只要 N>1 且外部性未完全内化，公地悲剧结构性存在，需总包统一管理/联保连坐内部化。 |
| MC 引擎升级 | 机械按 g0 分层反而变差（概率 +10%、CVaR +80%，诚实记录）；重要性采样 2000 样本逼近 5 万样本稀有概率（0.2585 vs 0.2677，ESS=576）；主动学习 40 点达 RMSE≈1.0（均匀需约 200 点，效率约 5×）。 |

## 六、边界与免责

- 参数为**示例标定值**（台账反演 + 文献区间），未经现场实测校准；用于方法演示与方案比选，不可直接作为具体工程的决策依据。
- 聚合型模型（无空间分辨率、无个体异质性）。
- v3 已补齐 v2 的多数结构性短板：I/f 解耦、事故闭环、两层不确定性、Sobol 全局敏感性、参数相关抽样、损失–停工相关、投入时滞、巡检质量衰减、巡检成本入账、CVaR、Wilson 区间、三阶段、马尔可夫天气、独立随机流、分级移交、校准诊断、分岔分析、CPM 进度冲击、全成本口径、RBF 代理模型（共 20 项，逐条见 [`docs/improvement_report.md`](docs/improvement_report.md)）。
- 仍待深化：贝叶斯在线更新参数、与 BIM 分区清单耦合、现场实测数据再标定、多阶段动态博弈（监管者学习更新）。
