# construction-safety-sd-mcs

**系统动力学（SD）+ 蒙特卡洛模拟（MCS）耦合的土木工程施工安全风险量化框架**

给定一笔安全投入和一套巡检安排，回答项目管理真正需要的三个问题：一个施工周期内至少发生一次事故的概率是多少？总成本的最坏情况（P95/P99）有多差？事故停工对进度基线的期望冲击有多大？

本项目是完整可复现的模型代码与实验脚本，并配有一篇约 2.9 万字符的论文（飞书文档）、七张矢量配图、单元测试与 CI。

## 一、模型概要

以"未整改隐患存量"为核心存量的存量—流量模型，日步长推演：

```
H(t+1) = H(t) + G(t) + W(t) - R(t)
G(t)   = g0 * (1 + β*H(t)) * (1 - η)           # 隐患生成（含正反馈放大）
η      = 1 - exp(-k_t * I)                     # 安全投入的培训抑制率
R(t)   = λ * H(t),  λ = 1 - exp(-(λ0 + k_d*f)) # 巡检整改，检出率封顶为 1
A(t)   ~ Poisson(θ * H(t))                     # 隐患→事故；只计数，不扣减存量
C      = I + Σ L_i + c_d * Σ D_i               # 总成本 = 投入 + 损失 + 停工损失
```

两处建模约定：

- **事故不消除隐患。** 事故发生后现场隐患通常仍然存在，若把每次事故从存量里扣除，会系统性低估存量、美化高风险方案；因此 `A(t)` 只作计数。
- **检出率封顶。** 线性式 `λ0 + k_d·f` 在巡检频次很高时会给出大于 1 的检出率，故改用指数封顶式，保证物理意义成立。

**随机参数（五维拉丁超立方抽样）**：隐患生成率 `g0`、事故触发系数 `θ`、损失中位数 `m_L`、停工中位数 `m_D`、巡检边际效应 `k_d`。`k_d` 在敏感性分析中影响最大，若固定处理等于默认"最敏感的参数恰好标定准确"，故纳入抽样。

**输出**：事故概率、期望事故次数、期望成本与 P95/P99、期望停工、期末隐患量，全部附 95% 置信区间（800 次 bootstrap；事故概率按二项标准误）。

## 二、共同随机数：让比较只反映参数差异

三套方案、九个投入档位、十二组敏感性扰动**共用同一组拉丁超立方样本（seed 2026）与同一随机数流（seed 7）**。这样：

- 方案 S2（I=20 万元）与扫描档位 I=20 万元结果完全相等（36.28 万元）；
- 敏感性分析的基准就是均衡方案本身（36.28 万元），不会出现"基准与主实验对不上"；
- 方案之间、档位之间的差异不含抽样噪声，可安全地把小幅差异解读为结构性差异。

代价是：不再能借用"不同种子互相印证"的粗糙借口，因此所有报告值都附置信区间。

## 四、运行与验证

```bash
pip install -r requirements.txt
python src/experiments.py   # 约 7 秒，输出 output/results.json 与 csv
python src/charts.py        # 生成 docs/figures/*.svg 与 docs/blocks/*.html
pytest -q                   # 单元测试
```

CI（GitHub Actions）在每次推送时跑一遍单元测试与完整实验，并校验关键指标是否落在预期区间内，作为回归保护。

## 五、主要结果（180 天周期，N = 6000）

| 方案 | 投入 | 巡检 | 事故概率 [95% CI] | 期望事故次数 | 期望总成本 [95% CI] | P95 成本 | 期末隐患 |
|---|---|---|---|---|---|---|---|
| S1 低投入 | 8 万元 | 0.32 次/天 | 48.1% [46.9, 49.4] | 0.66 | 46.3 [44.9, 47.6] | 155.4 | 10.6 |
| S2 均衡 | 20 万元 | 0.58 次/天 | 25.2% [24.1, 26.3] | 0.29 | 36.3 [35.4, 37.1] | 108.0 | 4.2 |
| S3 高投入 | 40 万元 | 1.00 次/天 | 11.9% [11.1, 12.8] | 0.13 | 47.4 [46.9, 48.1] | 98.9 | 1.7 |

四条结论：

1. **期望最优 ≠ 尾部最优。** 期望成本最低的是 20 万元方案（36.3 万元），P95 成本最低的是 40 万元方案（98.9 万元），二者相差 11.1 万元的均值差与 9.1 万元的 P95 差，且方向相反。
2. **边际效益的拐点在 20 万元。** 8→20 万元区间每万元投入削减事故概率 1.91 个百分点；20→40 万元区间降为 0.66 个百分点，约为前段的三分之一。P95 在整个 5—45 万元区间单调下降（177.1→95.1 万元），说明高投入买到的是确定性而非期望收益。
3. **敏感性集中在三处。** 巡检边际效应 `k_d`（±30% → 期望成本 +6.3/−3.2 万元）、隐患生成率 `g0`（+5.6/−4.1）、事故触发系数 `θ`（+5.3/−4.8）主导；天气扰动影响不足 1.6 万元。
4. **模型自洽。** 解析稳态解为 10.67/4.28/1.77 个，仿真期末存量为 10.61/4.27/1.76 个，相对误差均小于 1%。

## 六、边界与免责

- 参数为**示例标定值**（台账反演 + 文献区间），未经现场实测校准；用于方法演示与方案比选，不可直接作为具体工程的决策依据。
- 模型为聚合型（无空间分辨率、无个体行为异质性），投入—检出关系为指数封顶的近似式，未刻画巡检质量的边际衰减与投入时滞。
- 成本口径仅含投入、事故损失与停工损失，未含赶工费、保费上浮、监管处罚与声誉损失；若纳入，权衡会更偏向高投入方案。
- 改进方向：贝叶斯更新参数、幂函数饱和效应、分段标定、Sobol 全局敏感性、与 BIM 分区清单耦合。
